# ユニットテスト作成コマンド

指定されたファイルのユニットテストを作成してください。

## 使用方法

```
/add-test <対象ファイルのパス>
```

## 実行手順

### 1. 既存テストパターンの確認

プロジェクト内の既存の`.spec.ts`ファイルを確認し、テストの書き方やパターンを理解してください。

### 2. 対象ファイルの分析

指定されたファイルを読み取り、以下を特定してください：

- エクスポートされるクラス/関数
- 各メソッド/関数のシグネチャ
- 必要な依存関係やインポート

### 3. テストファイル作成

以下の要件でテストファイルを作成してください：

#### ファイル名

- `{元のファイル名}.spec.ts` の形式
- 元のファイルと同じディレクトリに配置

#### テストフレームワーク

- **Vitest**を使用（`describe`, `it`, `expect`, `beforeEach`など）
- 必要に応じて`vi.mock()`でモック化

#### テスト構造

- クラスの場合：各メソッドごとに`describe`ブロック作成
- 関数の場合：関数ごとに`describe`ブロック作成
- 各メソッド/関数の基本的な動作テストを実装

#### テスト内容

各メソッド/関数について：

- 正常系のテスト
- 異常系のテスト（該当する場合）
- 境界値のテスト（該当する場合）
- 戻り値の検証
- 副作用の検証（状態変更など）

#### コード品質

- 既存のテストコードスタイルに合わせる
- シンプルで読みやすいテストを作成
- 適切なモックデータを使用

## 注意事項

- 既存のテストファイルがある場合は上書きしない
- プロジェクトのコーディング規則に従う
- 統合テストではなく単体テストに焦点を当てる
