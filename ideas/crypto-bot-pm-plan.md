# 仮想通貨BotプロジェクトPM案（小資金スタート）

## 前提

- 初期資金: 1万円
- 目的: 利益率の高さを重視しつつ、再現性ある運用を構築
- 方針: 最初は「大きく稼ぐ」より「勝てる型の証明」を優先

## 実行方針（PM視点）

### 1. 戦略を3本に絞って短期検証（約2週間）

- `S1`: 先物グリッド（低レバ）+ トレンドフィルタ
- `S2`: 資金調達率（FR）逆張りの短期キャリー
- `S3`: Solana DEXアビトラ（最初はシミュレーション中心）

評価指標:

- 純利益率（手数料・スリッページ控除後）
- 最大ドローダウン（Max DD）
- 約定再現性（バックテストと実運用の乖離）

### 2. 1万円フェーズは実運用テストとして設計（約1か月）

- 常時リスクは元本の20-30%まで
- 1トレード損失上限は元本の0.5-1.0%
- 日次ログ: `PnL / 手数料 / スリッページ / 想定との差分`

目的:

- 月次の絶対額より、ルール通りに期待値が出るかを検証

### 3. 戦略の優先順位

- 最優先: `S1`（実装と改善サイクルが速い）
- 次点: `S2`（相場環境依存が強いためサブ運用）
- 拡張: `S3`（将来性は高いが、初期資金では優位性を作りにくい）

### 4. 増額ゲート（投資判断KPI）

30日ローリングで以下を満たした場合に増額:

- 純利益率 `+3%以上`
- 最大DD `-8%以内`
- 取引ログ欠損ゼロ
- 手動介入率5%未満

増額イメージ:

- 1万 -> 5万 -> 20万 -> 50万

### 5. 利益率重視の設計思想

- 「高レバで短期高収益」ではなく、コスト控除後の小さな優位を高再現で積む
- 初期は実績作り、増額後に複利効果を効かせる

### 6. 運用ルール（必須）

- 週次で戦略の継続/停止判定（キルスイッチあり）
- 月次の再最適化は1回のみ（過剰最適化防止）
- 障害時は全ポジション自動クローズ

## 要点

- 初期は `S1` 中心で短期に実績を作る
- 増額条件を満たしたら `S3` を段階導入して攻める
- 目的は「高利益率を持続可能に再現する運用体制」の構築
