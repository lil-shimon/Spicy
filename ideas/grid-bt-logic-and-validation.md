# Grid BT ロジックと検証方法（確定版）

## ロジック

- 取引所: KuCoin
- 対象: BTCUSDTM
- データ: 1分足OHLCV
- 戦略: 先物グリッドBot
- 探索範囲:
  - 本数（片側）: 3-10
  - レバレッジ: 1x-3x

## 検証方法

- 分割: 時系列 6:2:2（train/validation/OOS）
- 探索: 段階的グリッド探索
- コストモデル: 保守的固定値
- 約定失敗率: 0% / 2% / 5% の3ケース
- 制約反映:
  - 最低注文量
  - 価格刻み
  - レバ制約
  - 証拠金制約

## 採用判定

- OOS重視で判定する
- 既定の閾値:
  - OOSリターン > 0
  - OOS最大DD <= 8%
  - PF >= 1.05

## 方針

- まずはBTで勝ち筋の再現性を検証する
- 本番ロジックはBT採用結果に合わせて確定する
