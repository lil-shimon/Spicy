# Dirty Work - マーケットメイキングボットモジュール

このモジュールは、仮想通貨取引における自動マーケットメイキングボットを実装しており、MEXC取引所で動作するように設計されています。

## 概要

dirty-workモジュールは以下の自動マーケットメイキング機能を提供します：

- ビッド/アスク価格間のスプレッドレートを監視
- スプレッド条件を満たした時に買い・売り指値注文を発注
- 損益（P&L）とインベントリポジションを追跡
- 注文執行とキャンセルロジックを管理
- 取引データをCSVファイルに記録

## 主な機能

### マーケットメイキング戦略

- **スプレッドベースの取引**: 設定された閾値を超えた場合のみ注文を発注
- **両建て注文**: 中値周辺で買い・売り注文を同時発注
- **動的価格設定**: ティックサイズと市場状況に基づいて注文価格を調整
- **リスク管理**: キャンセル後の注文試行回数を制限

### 注文管理

- **タイムアウト処理**: 30秒以内に約定しない注文は自動キャンセル
- **約定追跡**: 注文ステータスを監視し、部分・全部約定を処理
- **キャンセル制限**: 2回以上のキャンセル後は取引を停止

### 損益追跡

- **リアルタイム在庫**: PUMPトークンとUSDTの残高を追跡
- **実現損益計算**: 各取引実行時に損益を更新
- **CSVログ**: タイムスタンプ付きで`pnl/pnl.csv`に損益データを記録
- **Discord通知**: 設定されたDiscord webhookに取引更新を送信

## ファイル構成

- **`bot.ts`** - メインのマーケットメイキングロジックと注文管理
- **`csv.ts`** - 損益データのCSVファイルへのログ記録
- **`spread.ts`** - スプレッドレート計算ユーティリティ
- **`round.ts`** - ティックベース価格設定用の価格丸めユーティリティ
- **`index.ts`** - モジュールエクスポート

## 設定

### 主要パラメータ

- **スプレッド閾値**: デフォルト0.1%（設定可能）
- **ティックサイズ**: 0.0001（市場データから自動検出）
- **注文数量**: シンボルごとに設定可能
- **タイムアウト**: 注文約定まで30秒

### 現在の設定

```typescript
const spreadThreshold = 0.1; // 0.1%スプレッド閾値
const TICK = 0.0001; // デフォルトティックサイズ
const FULL_SPREAD = 0.0001; // 価格設定用フルスプレッド
```

## 使用方法

### ボットの開始

```typescript
import { startDirtyWork } from './dirty-work';

// PUMP/USDTペアで数量2000、閾値0.2%でマーケットメイキング開始
startDirtyWork('PUMP/USDT', 2000, 0.2);
```

### パラメータ

- `symbol`: 取引ペア（例: 'PUMP/USDT'）
- `amount`: 各取引の注文サイズ
- `thresholdRate`: 注文をトリガーする最小スプレッドレート（デフォルト: 0.1%）

## 取引ロジック

1. **市場データ**: MEXC取引所からオーダーブックを取得
2. **スプレッドチェック**: ビッド・アスクスプレッドレートを計算
3. **閾値フィルタ**: スプレッド > 閾値の場合のみ処理継続
4. **注文発注**: 中値周辺で買い・売り注文を発注
5. **執行監視**: 約定またはタイムアウトまで注文ステータスを追跡
6. **損益更新**: 在庫と利益計算を更新
7. **クリーンアップ**: 未約定注文をキャンセルし、リトライロジックを管理

## リスク管理

- **注文制限**: キャンセル2回後は停止
- **タイムアウト保護**: 注文の最大継続時間30秒
- **スプレッドフィルタリング**: 利益性のあるスプレッドでのみ取引
- **在庫追跡**: リアルタイムポジション監視

## 依存関係
